# Shell Scripting Practice

## Overview
This repository contains my hands-on Shell Scripting practice as part of my DevOps learning journey.

## Topics Covered

1. Shell script basics and shebang
2. Variables and command substitution
3. Positional and special variables
4. Exit status and conditional statements
5. File and directory checks
6. For and while loops
7. Break and continue
8. Functions and function arguments
9. Case statements
10. User input using read
